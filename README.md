# Shindig — Milestone 1

A mobile-first invitation page for the Annualish Oyster Roast, built with Next.js, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

The RSVP flow uses browser state only. No submissions are persisted in Milestone 1.

## Deploy

Import the GitHub repository into Vercel and accept the detected Next.js defaults. No environment variables are required.
